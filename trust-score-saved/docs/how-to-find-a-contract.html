How to find a contract address

Open DexScreener, search ETH, copy the token contract from the pair page, then paste it into Token trust score. ETH is listed as WETH (Wrapped Ether), and the code starts with 0x.

1

Go to DexScreener

In your browser, open dexscreener.com.

2

Search ETH

Type ETH in the search box. Open an Ethereum pair — here, the first result, ETH / USDC.

3

Copy the ETH / WETH address

On the right-hand panel, click the ETH token (shown as WETH). Do not copy the pair address or USDC.

4

Paste it into the scanner

Open Token trust score, paste the address, then press Check.

Do not copy Pair or USDC. You want the WETH row: 0xC02…6Cc2. If it looks like a website, you have the wrong thing. The address is one long 0x code.
